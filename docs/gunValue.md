# LONGBOW M7 狙击枪参数详解

## 基础属性

| 参数 | 值 | 说明 |
|------|-----|------|
| `id` | `'sniper'` | 武器唯一标识符 |
| `name` | `'LONGBOW M7'` | 武器显示名称 |
| `cls` | `'BOLT-ACTION'` | 武器类型（栓动狙击枪） |
| `auto` | `false` | 是否全自动（false=半自动/栓动） |

---

## 伤害相关

| 参数 | 值 | 说明 |
|------|-----|------|
| `damage` | `92` | 基础伤害值（单发伤害） |
| `minDamage` | `0.9` | 远距离伤害衰减系数（0.9=最远距离仍保持90%伤害） |
| `range` | `140` | 有效射程（单位：米），超过此距离伤害开始衰减 |
| `pellets` | `1` | 每次射击射出的弹丸数量（狙击枪为1发） |

---

## 射速/冷却

| 参数 | 值 | 说明 |
|------|-----|------|
| `rpm` | `48` | 每分钟射速（Rounds Per Minute），48=约0.8秒/发 |
| `boltTime` | `0.85` | 栓动拉栓时间（秒），射击后拉栓上膛的延迟 |
| `adsTime` | `0.32` | 开镜瞄准时间（秒），右键开镜速度 |

---

## 弹匣/备弹

| 参数 | 值 | 说明 |
|------|-----|------|
| `mag` | `5` | 弹匣容量（5发） |
| `reserve` | `30` | 备用弹药总数（6个弹匣） |
| `reloadTime` | `3.1` | 普通换弹时间（秒） |
| `reloadEmptyTime` | `3.4` | 空仓换弹时间（秒） |

---

## 散布/精度

| 参数 | 值 | 说明 |
|------|-----|------|
| `spreadHip` | `0.085` | 腰射散布（不瞄准时子弹扩散范围），数值大=不准 |
| `spreadAds` | `0.0006` | 开镜散布（瞄准时精度），极小=激光枪 |
| `spreadMove` | `0.04` | 移动时散布加成（移动时会增加的散布值） |

---

## 后坐力

| 参数 | 值 | 说明 |
|------|-----|------|
| `recoilV` | `4.2` | 垂直后坐力强度（数值越大枪口上跳越严重） |
| `recoilH` | `0.5` | 水平后坐力强度（数值越大左右晃动越严重） |
| `aimKickUp` | `0.052` | 瞄准状态下枪口上跳幅度 |
| `kick` | `3.0` | 枪口整体冲击力（影响视觉抖动和准星恢复速度） |

---

## 瞄准/视野

| 参数 | 值 | 说明 |
|------|-----|------|
| `adsFov` | `0.36` | 开镜时视野缩放倍数（0.36=放大倍率约2.8倍） |
| `scope` | `true` | 是否使用狙击镜（true=有开镜特效） |
| `sightHeight` | `0.150` | 准星/瞄具高度（瞄准基线位置） |
| `adsZ` | `-0.32` | 开镜时武器在Z轴上的位置偏移 |

---

## 移动

| 参数 | 值 | 说明 |
|------|-----|------|
| `moveMult` | `0.88` | 移动速度倍率（0.88=持枪时移动速度为正常的88%） |

---

## 音效

| 参数 | 值 | 说明 |
|------|-----|------|
| `sound.kind` | `'sniper'` | 音效类型（狙击枪音效） |
| `sound.body` | `90` | 身体命中音效音量 |
| `sound.bright` | `4200` | 枪口火焰亮度/可见度 |
| `sound.dur` | `0.36` | 枪声音效持续时间（秒） |
| `sound.gain` | `0.85` | 音量增益（0.85=85%音量） |
| `sound.tail` | `true` | 是否有尾音（回声/余音） |

---

## 持枪位置

| 参数 | 值 | 说明 |
|------|-----|------|
| `hipPos` | `V(0.145, -0.14, -0.46)` | 腰射时武器在屏幕上的位置（X, Y, Z坐标偏移） |
| `hipRot` | `V(0.015, -0.05, 0.02)` | 腰射时武器的旋转角度（俯仰, 偏航, 滚动） |

---

```javascript
sniper: {
    id: 'sniper',
    name: 'LONGBOW M7',
    cls: 'BOLT-ACTION',
    auto: false,
    damage: 92,
    rpm: 48,
    mag: 5,
    reserve: 30,
    pellets: 1,
    spreadHip: 0.085,
    spreadAds: 0.0006,
    spreadMove: 0.04,
    recoilV: 4.2,
    aimKickUp: 0.052,
    recoilH: 0.5,
    kick: 3.0,
    adsTime: 0.32,
    adsFov: 0.36,
    scope: true,
    boltTime: 0.85,
    reloadTime: 3.1,
    reloadEmptyTime: 3.4,
    range: 140,
    minDamage: 0.9,
    moveMult: 0.88,
    sound: { 
        kind: 'sniper', 
        body: 90, 
        bright: 4200, 
        dur: 0.36, 
        gain: 0.85, 
        tail: true 
    },
    hipPos: V(0.145, -0.14, -0.46),
    hipRot: V(0.015, -0.05, 0.02),
    sightHeight: 0.150,
    adsZ: -0.32,
}
